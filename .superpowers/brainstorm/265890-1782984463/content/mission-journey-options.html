C. Product redesign

Most ambitious, but it adds new workflows and backend dependencies. Higher risk and not necessary to correct the current language.

Recommended guardrails

  • Quiet participation, never public performance
  • No rankings, popularity counts, or competitive progress
  • Direct handoff to each nonprofit
  • Private reminders that support repeat giving
  • Plain, universal, nonsectarian language

Current gaps to correct

  • Score and tier language competes with the mission
  • Volunteer status conflicts across pages
  • Knowledge sharing has no clear entry path
  • Wallet and account promises conflict
  • Some handoffs end without a useful next step
