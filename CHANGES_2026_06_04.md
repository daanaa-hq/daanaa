# Changes Deployed — June 4, 2026

## 1. Trust & Data Quality

### Deductibility Filter (Stricter)
- **Changed:** Only `deductibility = '1'` orgs shown in search (was allowing status 0, 1, 4)
- **Effect:** 182K non-deductible orgs completely hidden from directory
- **Guarantee:** "If giving is tax-deductible here, it's verified tax-deductible"

### Hourly IRS Status Check (New)
- **Script:** `scripts/hourly_irs_status_check.py`
- **Run:** Every hour at :00 via cron
- **Action:** Detects revoked/deductibility-changed orgs, removes from public search
- **Log:** `logs/irs_status_check.log`
- **Benefit:** Catches status changes within 60 minutes vs daily

- Benefit: Average donor sees **one primary signal** per context, details on demand
