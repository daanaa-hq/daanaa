# Core Platform Definition — "Free Forever"

**Status:** Adopted and binding · 2026-07-14  
**Authority:** Founder decision (FD-002) · Stewardship Principle 1 (mission before growth)  
**Effective:** Immediately; all features and pricing decisions must align with this definition

---

## What Is the "Core Platform"?

The Daanaa core platform is the set of features and services that remain **free forever**, on equal terms for every organization, and are never paywalled, never restricted by payment tier, and never monetized through Daanaa in ways that could influence visibility, scoring, or treatment.

---

## Seven Core Platform Features

### 1. Discovery and Research
- **Browsing:** View any of the 1.7M organizations in the directory
- **Search:** Full-text search by organization name, location, NTEE category, mission keywords
- **Filtering:** Filter by state, city, cause, revenue band, financial health signal, archetype
- **No login required:** Anyone can browse without creating an account

### 2. Peer Financial Context
- **Scores and percentiles:** See how an organization ranks within its financial peer group
- **Health signals:** HEALTHY / STABLE / CAUTION classification based on financial reserves and trends
- **Archetypes:** Funding model (Donation-Funded, Fee-for-Service, Endowment-Funded) and revenue band (Micro, Professional, Established)
- **Peer comparison:** View similar organizations in the same peer group
- **Published publicly:** All context is visible on the organization's public profile page

### 3. Organizational Profiles
- **Public record:** Name, location (street address), EIN, NTEE category, mission statement, website, leadership (from IRS 990 public records)
- **Financial data:** Revenue, expenses, assets, liabilities, employee count (from Form 990)
- **History:** Link to original Form 990 filing and ProPublica data source
- **Website:** Verified link to organization's own website
- **Donation link:** Verified link to where the public can give to this organization

### 4. Correction Mechanism
- **Visible correction button:** Every organization page displays a way to report an error, clarification, or correction
- **Organization can claim:** Organizations can verify their identity and claim their profile to provide corrections and custom data
- **Corrections are public:** Corrections and clarifications are recorded and visible (part of Stewardship Principle 6)
- **No paywall:** Correction rights apply equally to all organizations

### 5. Nonprofit Dashboard (When Claimed)
- **Access:** Available to any organization that verifies ownership (via email link or admin concierge call)
- **Content:** 
  - Custom mission statement (if the organization provides one)
  - Peer financial context snapshot (same scores visible to public)
  - Discovery interest aggregates (how many people have bookmarked/viewed this org over time)
  - Profile completeness score (website, donation link, mission — all factors)
  - Volunteer interest (how many people expressed interest in helping)
- **No analytics:** No pageview tracking, no donor identification, no inference about who is interested
- **Free:** Dashboard access is never paywalled

### 6. Data Export
- **Full export:** Organization can export every piece of data they have given to Daanaa (custom mission, contact emails, phone numbers, notes, attestations, dashboard activity)
- **Machine-readable format:** CSV or JSON export, suitable for import into other systems
- **No login fee:** Export is free and always available
- **Stewardship Principle 9:** Operationalizes the right to export entrusted data

### 7. Data Deletion
- **Full deletion:** Organization can delete everything they have entrusted to Daanaa with one action
- **Irreversible:** Once deleted, it cannot be recovered by Daanaa or the organization
- **Public record remains:** IRS data is not deleted (it is public record and not owned by Daanaa)
- **Immediate:** Deletion takes effect immediately; cached/indexed data is flushed
- **Stewardship Principle 9:** Operationalizes the right to delete entrusted data

---

## What Is NOT in Core (Reserved for Optional Services)

These features are useful but are not part of "free forever" and may be developed as optional, paid services if there is demand:

- **Advanced reporting:** Custom reports, peer comparison deep dives, historical trend analysis
- **Bulk data export:** API access to download data for multiple organizations or bulk research
- **White-label or embedded:** White-labeled version of Daanaa for use on another organization's website
- **Consulting or advisory:** Professional services (offered by EcoMargins Consulting LLC under its own name, never inside Daanaa)

---

## How This Protects the Mission

**Principle 1 (mission before growth):**  
Daanaa's core—discovery, peer context, corrections, privacy—costs little to operate and serves everyone equally. Restricting core features would undermine the mission.

**Principle 5 (no size-based advantage):**  
A small community nonprofit gets the same discovery, context, and correction tools as a national organization. Paid features enhance, but never diminish, smaller organizations' visibility.

**Principle 8 (independent from money):**  
Daanaa's revenue model (if developed) cannot depend on organizations paying to be found or visible. The core platform remains free.

---

## Commitment to This Definition

If this definition ever needs to change (e.g., "we must charge for the platform because the cost of operation exceeded our budget"), the change will:

1. Be announced publicly with at least 90 days' notice
2. Revise this document in daylight with explanation
3. Offer a transition period for organizations to export their data
4. Never apply retroactively to data already entrusted to Daanaa

Silent weakening of this commitment is a Stewardship Principle 11 violation.
