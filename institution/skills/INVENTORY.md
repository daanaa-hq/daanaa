# Skills Inventory

## Document Control

| Field | Value |
|---|---|
| Purpose | Track the minimum implemented stewardship skills and defer broader skill growth until repeated need is proven. |
| Responsible role | Stewardship Systems Agent. |
| Authority level | Operating inventory subordinate to `AUTHORITY.md`. |
| Review trigger | Weekly review, repeated manual work, or capability gap. |
| Editable status | Editable by ordinary agents with evidence. |
| Dependencies | `CONTINUOUS_IMPROVEMENT.md`, `HYPOTHESES.md`, `scripts/institution_weekly_review.py`, `institution/skills/`. |
| Retirement condition | Retire when replaced by a maintained skill registry with equal or stronger traceability. |

## Current Implementation

Not implemented now:

- Additional skills beyond the minimum operating loop
- Scheduled automation for the weekly review
- External-research workflows that require current authoritative internet verification

## Rule

Do not add more skills until repeated work demonstrates that the current set is insufficient.
