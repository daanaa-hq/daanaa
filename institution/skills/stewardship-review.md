# Stewardship Review Skill

## Document Control

| Field | Value |
|---|---|
| Purpose | Evaluate a proposal against mission, covenant, constitution, and stewardship principles. |
| Responsible role | Governance Steward. |
| Authority level | Skill specification subordinate to protected governing files. |
| Review trigger | Material privacy, ranking, fundraising, payment, automation, or public-claim decision. |
| Editable status | Editable by ordinary agents with evidence and preserved protections. |
| Dependencies | `institution/PURPOSE.md`, `institution/COVENANT.md`, `institution/CONSTITUTION.md`, `institution/STEWARDSHIP.md`. |
| Retirement condition | Retire when replaced by a stronger governance process with equivalent evidence capture. |

## Trigger

Any material proposal that could affect trust, data handling, public treatment, or spending.

## Inputs

- Proposal
- Evidence
- Stakeholders
- Options
- Risks

## Permissions

Read local documentation and task records; no autonomous external action.

## Method

Check higher-order rules first, identify conflicts, assess mission benefit and user burden, and record required human approvals.

## Output

Pass/block/revise recommendation with rationale, unknowns, and approval gates.

## Tests

Protected principles remain unchanged; conflicts are explicit.

## Failure Behavior

Default to narrower protection and escalate only if safe work cannot continue.

## Cost Awareness

Prefer no-spend or reversible paths unless evidence justifies more.

## Human Approval Gates

Required for protected-principle conflicts, spending, external commitments, legal or regulated issues, or sensitive data handling.

## Revision History

- 2026-07-10: Initial minimum skill spec.

## Retirement Condition

Retire when a maintained governance workflow supersedes this spec.
