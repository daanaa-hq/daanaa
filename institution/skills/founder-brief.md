# Founder Brief Skill

## Document Control

| Field | Value |
|---|---|
| Purpose | Convert operational detail into a concise, decision-ready founder brief. |
| Responsible role | Stewardship Systems Agent. |
| Authority level | Skill specification subordinate to `GOVERNANCE.md` and founder approval policies. |
| Review trigger | Weekly review, blocked approval gate, or material incident. |
| Editable status | Editable by ordinary agents with preserved brevity and honesty requirements. |
| Dependencies | `institution/FOUNDER_REQUESTS.md`, `institution/reviews/`, `institution/state.json`. |
| Retirement condition | Retire when a better founder reporting workflow exists. |

## Trigger

Manual weekly review or any material issue needing founder attention.

## Inputs

- Current state
- Highest constraint
- Recommended next action
- Open founder requests

## Permissions

Read local records; write founder brief only.

## Method

Compress institutional detail to progress, concern, constraint, recommendation, resource ask, approval requests, and safe continuing work.

## Output

One concise founder brief with explicit confidence.

## Tests

No invented financial or operational facts; approval asks are narrowly scoped.

## Failure Behavior

If evidence is incomplete, mark it unknown and preserve safe defaults.

## Cost Awareness

Highlight spending requests only when necessary and justified.

## Human Approval Gates

The brief itself requests, but does not grant, approvals.

## Revision History

- 2026-07-10: Initial minimum skill spec.

## Retirement Condition

Retire when a better founder briefing system exists.
