# Funding Pipeline

## Document Control

| Field | Value |
|---|---|
| Purpose | Track funding and partnership opportunities without auto-submission. |
| Responsible role | Funding Steward; Chief Steward approves submissions. |
| Authority level | Pipeline memory; not authorization to apply or commit. |
| Review trigger | Weekly review, deadline change, new opportunity, or founder update. |
| Editable status | Editable by ordinary agents with current authoritative sources. |
| Dependencies | `BUDGET_STATE.md`, `FOUNDER_REQUESTS.md`, `GOVERNANCE.md`. |
| Retirement condition | Retire when replaced by CRM/grant management system. |

## Rules

- Never auto-submit applications.
- Verify status, deadline, eligibility, geography, restrictions, matching, reporting burden, entity eligibility, partner/fiscal-sponsor fit, effort, probability, mission alignment, and control implications from current authoritative sources before recommending action.
- Do not alter Daanaa's structure merely to appear eligible.
