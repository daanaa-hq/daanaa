# Charter Alignment Review

Date: 2026-07-13

This file summarizes the current charter alignment. Detailed recommended redlines, clean draft, and promise-to-control matrix are in `institution/publication-drafts/DAANAA_CHARTER_REVIEW.md`.

## Summary

The charter is coherent and institutionally valuable. It names the right promises. The main issue is not intent; it is evidentiary support for absolute claims.

## Promise Status

| Promise | Current Status | Main Gap |
|---|---|---|
| Never take a cut of a donation | Aligned | Need unified donation boundary policy for links/logging/letters. |
| Never sell anything inside Daanaa | Aligned but requires implementation review | Settings opt-in door and consulting firewall need demonstrable controls. |
| Never use entrusted data to sell to users | Aligned but requires implementation | Public code-gate claim is ahead of visible `privacy_check.sh` coverage. |
| Never sell or share data | Wording should be narrowed | Research, aggregate data, service providers, legal process, business transfer, and public records need careful exceptions. |
| Never charge for the platform | Wording should be narrowed | Define core platform vs optional paid capacity services. |
| Never let money shape truth | Aligned | Needs recurring audit evidence and relationship-to-outcome review. |
| Never shame organizations | Aligned | Continue UI/copy reviews for labels, score sort, and visual hierarchy. |
| Never hide mistakes | Aligned but requires implementation | Public correction log and response SLA should be evidenced. |
| Never lock users in | Aligned but requires implementation | Export/delete controls exist for claims; wallet/org data scope must be unified. |
| Never weaken charter quietly | Aligned | Needs amendment log process and publication procedure. |

## Claims Not Ready For Final Publication Without Qualification

- "This is enforced in our code" for the Daanaa/EcoMargins Tier 2 firewall.
- "Audited quarterly" unless the first quarterly self-audit process and record exist.
- "Every core tool we build for nonprofits is free" until "core tool" is defined.
- "Never sell or share your data" without service-provider, legal-process, public-record, and explicitly consented research carveouts.
- "You will get an answer from a human" unless staffing and response expectations are defined.

## Highest Priority Charter Controls

1. Tier 2 firewall test coverage and privacy gate update.
2. Donation boundary policy.
3. Core-free vs optional-paid services definition.
4. Public correction log and response standard.
5. Charter amendment and public announcement procedure.
