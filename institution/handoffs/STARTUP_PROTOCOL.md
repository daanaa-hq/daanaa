# Startup Protocol

Read this first in every Claude or Codex window.

1. Read the governing files required by `AGENTS.md`.
2. Read the current task record and latest handoff note.
3. Use `scripts/task_handoff_packet.py` or the latest checkpoint to recover state.
4. Write the next action to the shared repo before editing.
5. Keep Claude as the implementer/checkpoint voice and Codex as the reviewer/skeptic voice.
6. If a fact is load-bearing and missing, stop and surface it.
