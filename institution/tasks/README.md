# Task Records

## Document Control

| Field | Value |
|---|---|
| Purpose | Define the minimum durable task record used for Claude Code-Codex coordination. |
| Responsible role | Product Engineering Steward and Stewardship Systems Agent. |
| Authority level | Operating record format subordinate to `HANDOFF_PROTOCOL.md`. |
| Review trigger | New shared task, ownership confusion, or recurring handoff failure. |
| Editable status | Editable by ordinary agents; task history should be appended, not erased. |
| Dependencies | `institution/HANDOFF_PROTOCOL.md`, `institution/AUTHORITY.md`. |
| Retirement condition | Retire when replaced by a repository-visible task system with equivalent traceability. |

## Required Task Fields

- Identifier
- Date opened
- Owner
- Scope
- Affected paths
- Higher-authority constraints checked
- Status
- Validation plan
- Review notes
- Handoff target
- Merge or close-out note
