================================================================================
TROUBLESHOOTING
================================================================================

If health check restarts loop:
  → Check: cat ~/meritgiving/logs/health_check_state.json
  → Reset: echo '{"restarts": [], "last_restart": null}' > health_check_state.json

If backup verification fails:
  → Check: ls -lh ~/meritgiving/backups/
  → Must be > 1GB and < 24 hours old

If database optimization slows queries:
  → Revert specific index: DROP INDEX idx_name
  → Rerun optimization: python3 scripts/create_database_indexes.py

If cron jobs don't run:
  → Verify: sudo cat /etc/cron.d/daanaa-maintenance
  → Check syslog: grep daanaa-maintenance /var/log/syslog
