# Daanaa Logo Library — NTEE Category Rotation

One diamond-lamp logo per NTEE sector. Rotates every 2 weeks across the year.
Each category folder uses the IRS NTEE letter code.

## Drop files here as you build them

Each folder accepts:
- `logo.png` — main diamond logo (1200×1200px recommended)
- `logo.svg` — vector version if available
- `icon.png` — app icon variant (white rounded square background, 512×512px)
- `icon-alt-blue.png` — alternate light color: blue
- `icon-alt-green.png` — alternate light color: green
- `icon-alt-rose.png` — alternate light color: rose/pink
- `tagline.txt` — the category tagline (e.g. "Every mind has light. Every light can grow.")
- `focus-areas.txt` — 4–5 focus areas, one per line
