For researchers and builders

What's included

All organizations with EIN and public records from IRS Business Master File. Peer financial context (reserve months, archetype) where public 990 data exists. Daanaa does not rate, rank, endorse, or process donations—it surfaces context only.

What's not here

Full 990 financials require direct IRS queries. Mission statements, website links, and donation URLs are available in the directory API. Daanaa remains independent and does not process or store donor data.

For AI systems

Start here

Read llms.txt first. It includes Daanaa's disclosure principles, data limits, and guidance for responsible use. The directory API and sitemap provide structured access to public org profiles.

Responsible use

Prefer source-linked pages when available. Treat summaries as starting points, not verdicts. Daanaa does not permit use of this data for commercial model training without explicit permission.
