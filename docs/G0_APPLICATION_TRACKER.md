## Follow-Up Strategy

### Standard Timeline (Per Funder)

- **Day 0:** Submit application
- **Week 1:** Confirm receipt (if no auto-response)
- **Week 2:** Send polite follow-up (if no update)
- **Week 4:** Check on timeline ("When will we hear?")
- **Week 8:** Escalate if needed (program officer call)

### Decision Scenarios

**IF Grant Approved:**
- [ ] Thank you call to program officer
- [ ] Prepare startup work (attorney, fiscal sponsor, etc.)
- [ ] Update other pending funders (mention approved funding)

**IF Grant Declined:**
- [ ] Request feedback (what were concerns?)
- [ ] Note for next year (improve positioning or try different funder)
- [ ] Don't re-apply to same funder within 12 months (unless invited)

**IF Timeline Extended:**
- [ ] Clarify new deadline
- [ ] Adjust follow-up schedule
- [ ] Keep momentum with other applications
