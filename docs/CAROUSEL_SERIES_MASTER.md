# Daanaa Daily Carousel Series — Master Plan

**Goal:** 90-day educational series on public problems + nonprofit response + Daanaa data support  
**Cadence:** 1 carousel/day  
**Format:** Locked 8-slide template (no redesign, content only)  
**Audience:** Donors, sector leaders, public  
**Philosophy:** Problem-first. Data-backed. Daanaa as optional support, not sales pitch.

---

## LOCKED FORMAT (Do Not Change)

Every carousel follows this 8-slide structure:

**SLIDE 1: PROBLEM STATEMENT**
- Label: (blank or "THE CHALLENGE")
- Headline: The public problem (make it visceral)
- Subheadline: Scale/urgency (1-2 numbers)
- Design: Dark background, minimal text, emotional framing

**SLIDE 2-4: INVESTIGATION (3 slides)**
- Label: Rotating ("WHAT'S HAPPENING" / "ON THE GROUND" / "THE DATA")
- Headline: Key insight or finding
- Body: Context + research findings
- Source: Industry article/research org cited
- Design: One data point or narrative per slide

**SLIDE 5-6: NONPROFIT RESPONSE (2 slides)**
- Label: "THE NONPROFITS" / "THE GAP"
- Headline: Scale of nonprofit work + funding reality
- Body: How many nonprofits, what they do, why underfunded
- Source: Daanaa data + external research
- Design: Contrasts (what's needed vs what's happening)

**SLIDE 7: DAANAA SUPPORT**
- Label: "HOW DAANAA HELPS" (or "YOU CAN SUPPORT")
- Headline: Optional offer (not pushy)
- Body: "Want to explore these nonprofits? Daanaa has financial data + discovery tools"
- Design: Light, inviting, no hard sell
- Link: daanaa.org/[cause]

**SLIDE 8: CLOSE**
- Headline: "Learn more" or call to reflection
- Body: "Public data. Public good. Transparent giving."
- Design: Minimal, elegant

## DAILY WORKFLOW

### Step 1: Content Research (Morning)
- Pick topic from 90-day map
- Gather 3-5 research sources
- Pull Daanaa data (nonprofit counts, financial context)
- Compile in Google Doc (template provided)

### Step 2: Draft Carousel Content
- Fill in 8-slide template with research
- Headline: Emotional + specific (not clickbait)
- Body: Data + context (cite sources)
- Sources clearly attributed
- Daanaa hook: Optional, not pushy

### Step 3: Review (You)
- Read for accuracy (data, claims)
- Check tone (educational, not sales)
- Verify sources are credible
- Approve or request changes

### Step 4: Generate PDF
- Use locked carousel_generator template
- No design changes
- Only content varies
- Auto-publish to output folder

### Step 5: Post
- LinkedIn publish (manual or automated)
- Track engagement
- Log topic completion
