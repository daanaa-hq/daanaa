## Design Elements That Drive Engagement

### Visual Hierarchy
- **Bold headlines** that are questions or surprising statements
- **Bullet points** for scannability
- **Call-to-action buttons** (blue, clear)
- **Icons** for quick visual scanning (📊 📈 ⚠️ 🔍)
- **Color-coded confidence** (✅ ⚠️ ❌) for transparency

### Interactive Elements (Low-Effort, High-Value)
1. **"See X nonprofits that match this profile"** → Links to filtered directory
2. **"Try it yourself"** → Mini-action (search your nonprofit, check reserves)
3. **Heat map / visualization** → Hover for details
4. **Data tables with sort** → User explores
5. **Downloadable PDF** → Shareable, citable

### Skills Sections
Each article teaches 1-3 practical skills that readers can use immediately:
- "Spot a healthy nonprofit" (3 things to check)
- "Claim your profile" (5 steps, 5 min)
- "Evaluate before you give" (checklist)
- "Search by sector" (how-to)
- "Interpret peer ranking" (what the data means)

### SEO Optimization
- **Title:** Question form + keywords ("What... 2026... Shows")
- **Meta description:** Hook + benefit (43-160 chars)
- **Headers:** H2s answer common search queries ("What's broken?", "What can I do?")
- **Internal links:** 8-12 links to related content/directory
- **Images:** Alt text describes data
- **Schema markup:** Article + FAQPage
- **Keywords:** Naturally woven (not stuffed)

### Shareability
- **TL;DR:** 3-5 tweetable bullets at top
- **Quote-worthy**: Pull out 2-3 surprising stats as callouts
- **Clear CTAs:** "Discover orgs in your area" / "Learn more about this sector"
- **Social meta tags:** og:image, og:title, twitter:card

## Why This Format Works

1. **Skimmable** — Someone can get value in 2 minutes (TL;DR + key stats)
2. **Deep** — Someone can spend 12 minutes and learn real things
3. **Actionable** — Skills sections give people something to *do* today
4. **Trustworthy** — Limitations and sources are transparent
5. **Discoverable** — SEO + social meta tags reach people searching for this
6. **Shareable** — Easy to tweet a stat, link to a skill, send to a friend
7. **Durable** — Evergreen content that ranks for 2+ years
