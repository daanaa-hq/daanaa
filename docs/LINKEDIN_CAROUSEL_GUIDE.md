## How to Use

### Option 1: View & Share Directly
1. Open any `.html` file in a browser
2. Screenshot each slide (1080x1080px is ideal for LinkedIn)
3. Upload to LinkedIn carousel post

### Option 2: Export to Images (Best for LinkedIn)
1. Open each HTML file in browser
2. Use Chrome DevTools → Device Toolbar (1080x1080px)
3. Print to PDF or screenshot each slide
4. Upload slides to LinkedIn carousel (they handle the formatting automatically)

### Option 3: Open HTML Files in Figma (Advanced)
If you want to edit colors or text:
1. Export each HTML to PNG at 1080x1080px
2. Import into Figma as background image
3. Overlay text/shapes for customization
4. Export final slides

## What Each Slide Emphasizes

### The Daanaa Vision
- **Slide 1**: Hook — 17 principles that make giving easy
- **Slide 2**: Principle 1 (Make Giving Easy) — frictionless discovery
- **Slide 3**: Principle 4 (Small Org Fairness) — 514K underserved orgs deserve dignity
- **Slide 4**: Principle 5 (Context Not Verdict) — show comparison, not ranking
- **Slide 5**: Principle 7 (Independence) — no paid placement, ever
- **Slide 6**: Key insight — transparency is a tool
- **Slide 7**: Call to explore the 17 principles
- **Slide 8**: CTA to full vision

### AI Governance
- **Slide 1**: Hook — stewardship over compliance
- **Slide 2**: Problem — compliance rules break when tech changes
- **Slide 3**: Solution — stewardship beats rules
- **Slide 4**: Obligations 1-2 (Mission, Oversight)
- **Slide 5**: Obligations 3-5 (Explainability, Provenance, Correction)
- **Slide 6**: Obligations 6-9 (Appeals, Ethics-First)
- **Slide 7**: Conclusion — responsibility doesn't scale
- **Slide 8**: CTA to full framework

### Peer Financial Context
- **Slide 1**: Hook — how to measure fairly with incomplete data
- **Slide 2**: Central claim — missing data is a condition, not weakness
- **Slide 3**: Framework — five evidence states for honest labeling
- **Slide 4**: Critical rule — never map missing data to ranking
- **Slide 5**: Validation — what coverage audits need to show
- **Slide 6**: Robustness — sensitivity testing matters
- **Slide 7**: Red-team cases — test the hard cases first
- **Slide 8**: CTA to full research brief
