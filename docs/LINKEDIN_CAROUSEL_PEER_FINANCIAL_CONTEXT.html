THE CENTRAL CLAIM
Missing evidence is a data condition
Not evidence of weakness. Not evidence of danger. An information condition.
When we can't calculate financial context because the public filing is incomplete or stale, we should say so—not silently penalize the org.

FRAMEWORK
Five evidence states
5
ways to honestly label what we know
Context Available — enough data to calculate
Partial Evidence — some data, not enough
No Usable Evidence — can't calculate responsibly
Stale Evidence — data exists but is too old
Under Review — conflicts or corrections pending

CRITICAL RULE
Never map missing data to ranking
An org without a recent filing shouldn't drop in visibility or in peer percentile rank.
Missing data shouldn't be a hidden penalty. It should be an honest label.
If we can't verify it, we say so. We don't infer weakness from silence.

VALIDATION NEEDED
Coverage audits
What % of orgs have context available vs partial vs none?
Does availability correlate with size, geography, sector, or language?
Are we inadvertently penalizing resource-constrained communities?
These questions need answers before we publish at scale.

ROBUSTNESS
Sensitivity matters
Small changes in freshness windows should not dramatically reshuffle peer groups.
Small changes in revenue bands should not move orgs in/out of comparison cells.
If the methodology is sensitive to minor tweaks, donors can't trust the result.
→ daanaa.org/pages/peer-financial-context.html
www.daanaa.org
6 / 8
EDGE CASES
Test the hard cases
Small, healthy, financially sound orgs (hidden gems)
New and growing orgs (incomplete filing history)
Community-rooted orgs with limited English materials
Crisis-affected orgs (reserves just deployed)
If our model fails them, we have a fairness problem.
