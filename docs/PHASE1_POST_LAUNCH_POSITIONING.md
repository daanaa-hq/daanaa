## AFTER PHASE 1: DAANAA WITH CREDIBILITY SIGNALS

### Credibility Signals (Post-Phase 1)

**6 New Trust Indicators:**

1. **IRS Verification** — "Is this org's 501(c)(3) status current?"
   - Signal: Verified / Unverified / Revoked
   - Confidence: 0-100%
   - User benefit: Know immediately if org is in good standing (caught within 24h if revoked)

2. **Data Freshness** — "How recent is this org's financial data?"
   - Signal: Fresh (<18mo) / Aging (18-30mo) / Stale (>30mo)
   - Confidence: 90%
   - User benefit: Understand if financials are current or outdated

3. **Expense Ratio** — "What % goes to programs vs overhead?"
   - Signal: Shows actual % + peer median for context
   - Confidence: 95%
   - User benefit: Transparent program spend, not a shame label

4. **Peer Context** — "How does this org rank within peers?"
   - Signal: Leader / Strong / Typical / Developing (percentile rank)
   - Confidence: 85%
   - User benefit: Fair comparison (small org vs small org, not vs Kaiser)

5. **Recency & Completeness** — "How complete is this org's profile?"
   - Signal: Complete / Partial / Minimal (% of key fields populated)
   - Confidence: 100%
   - User benefit: Know what data gaps exist (mission missing? website not verified?)

6. **Mission Alignment** — "Is this mission from the org or AI-generated?"
   - Signal: Org-Attested / AI-Generated / Unknown
   - Confidence: 70-100%
   - User benefit: Know if mission came from org's own website/990 or was AI-inferred

### User Experience (Post-Phase 1)

**What's Different:**

1. **Signals on Every Org Page**
   - 6 trust indicators + composite confidence score
   - Each signal shows: Status + Confidence + Explanation
   - Example: "IRS Status: Verified (100% confidence) — Current 501(c)(3) status confirmed in IRS database (verified daily)"

2. **Donor Confidence Loop**
   - User sees score: 72/100
   - Clicks → sees 6 signals explaining the score
   - Understands: "Oh, I trust this because IRS verified it, data is fresh, peers are similar, program spend is strong"
   - Action: Donate with confidence (or ask questions if gaps exist)

3. **Small Org Visibility**
   - 200K postcard nonprofits now searchable (were invisible before)
   - Small org CAN rank high if financially healthy for peer group
   - Fair comparison: $200K community org vs $200K peers (not vs $5B foundations)

4. **Transparent Data Gaps**
   - If mission is missing: "Data: Minimal" (not shame, just honest)
   - If website not verified: Signals show it
   - Donor sees "this org has limited public presence, but IRS verified them, so proceed with confidence"

### GiveWell
**What they do:** Rate 4-5 charities per cause, deep research, publish rankings  
**Credibility:** Very high (expert analysis)  
**User-friendliness:** Low (only 4-5 choices per cause, hard to find your org)  
**Daanaa advantage post-Phase 1:** 2.26M orgs searchable + 6 trust signals + no ranking (we inform, not rank)

### Charity Navigator
**What they do:** Financial grades (A-F), charity ratings, 4-star system  
**Credibility:** High (accepted as industry standard)  
**User-friendliness:** Medium (ratings exist, but why does THIS org get 3 stars?)  
**Daanaa advantage post-Phase 1:** Evidence-based signals (6 visible data points) + no shaming language + small org fairness

### GuideStar / Candid
**What they do:** Directory of 501(c)(3) orgs, basic financials, some ratings  
**Credibility:** Medium (data is there, but not contextualized)  
**User-friendliness:** Medium (search works, but trust signals are weak)  
**Daanaa advantage post-Phase 1:** 6 layered signals + peer context + mission transparency + daily revocation sync

### Daanaa (Post-Phase 1)
**What we do:** 2.26M orgs + 6 trust signals + fair peer benchmarking + evidence-based confidence  
**Credibility:** High (Stewardship + Charter enforce it, 21/21 principles)  
**User-friendliness:** High (6 signals on every page, no jargon, no shame)  
**Unique positioning:** "Trust signals from real data, fair to small orgs, honest about gaps"
