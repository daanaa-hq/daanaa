# Test Coverage Gaps

## Confirmed test strengths

- Claim flow tests.
- Search reliability tests.
- Principle tests.
- Wallet/security tests in the frontend test suite.

## Gaps

- Many scripts appear to have no direct automated tests in the repo snapshot.
- Language-governance checks are present in concept across some tests, but there is no dedicated repository-wide terminology inventory test yet.
- Some production-edge behaviors may only be covered indirectly through a small number of targeted tests.
