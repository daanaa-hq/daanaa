# Approved Language Standard

## Financial context

- Approved definition: a public-data-based contextual comparison of a nonprofit's financial position relative to similar organizations.
- Public wording: "financial context" or "peer financial context."
- Technical wording: deterministic context calculation, peer benchmark, percentile, reserve comparison.
- Wording to avoid: "quality score", "objective score", "impact score" unless separately defined and evidenced.
- Reason: these phrases can overstate certainty.
- Acceptable usage: "This nonprofit's financial context is based on public IRS filing data."
- Misleading usage: "This nonprofit is objectively strong."

## Peer comparison

- Approved definition: comparison within a similar nonprofit set.
- Public wording: "peer comparison."
- Technical wording: peer group, percentile within group.
- Avoid: "ranking of worth."
- Reason: the comparison is contextual, not moral.
- Acceptable: "Compared with similar organizations."
- Misleading: "Top nonprofits."

## Context score

- Approved definition: numeric shorthand for a calculated context output.
- Public wording: "context score" only when clearly explained.
- Technical wording: deterministic percentile or banded context metric.
- Avoid: "AI score" if no model is used.
- Reason: deterministic outputs should not be mislabeled.
- Acceptable: "calculated context score based on public data."
- Misleading: "AI decided this score."

## Identity verification

- Approved definition: a bounded check of claim authority or account control.
- Public wording: "verification" only with the checked factor named.
- Technical wording: phone verification, email verification, attestation, admin review.
- Avoid: "verified nonprofit" as a blanket status.
- Reason: verification is partial and scope-limited.
- Acceptable: "phone-verified claim contact."
- Misleading: "verified by Daanaa" without scope.
