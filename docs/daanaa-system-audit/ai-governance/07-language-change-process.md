# Language Change Process

1. Maintain an approved glossary for donor-facing terms and AI-governance terms.
2. Require founder review for any change that touches score, ranking, verification, trust, or recommendation language.
3. Require legal review for any language that could imply certification, endorsement, or regulated advice.
4. Require technical verification that the wording matches implemented behavior.
5. Require human review from nonprofit or donor representatives when the wording affects their decision path.
6. Version terminology changes in the same way as code or policy changes.
7. Add repository searches or tests for restricted phrases.
8. Record exceptions with file references and a sunset date.
