# High-Risk Language

| Phrase | Risk | Misleading context | Status | Safer alternative | Required disclosure | Human approval |
|---|---|---|---|---|---|---|
| Best nonprofit | Implies moral ranking | Search result or profile badge | Prohibited | Featured organization or peer context | State that Daanaa does not certify best | Yes |
| Most effective nonprofit | Overstates causal inference | Financial context page | Restricted | Financial context comparison | Explain what the metric does and does not measure | Yes |
| Trusted nonprofit | Implies endorsement | Public profile | Restricted | Reviewed data / public data shown | Note that Daanaa is not certifying trust | Yes |
| Verified by Daanaa | Implies universal certification | Any public page | Restricted | Verified for [specific field] | Scope of verification | Yes |
| AI decided | Removes human accountability | Claim, score, or ranking copy | Prohibited | AI-assisted / software-calculated | Name the human decision point | Yes |
| Objective score | Overstates certainty | Score pages | Prohibited | Calculated context score | Explain inputs and limitations | Yes |
