# Public Explanation Recommendations

Use plain language such as:

- "Daanaa helps people discover nonprofits using public records and contextual comparisons."
- "Daanaa is not a rating agency and does not certify nonprofits."
- "Some outputs are calculated automatically from public data; some AI-assisted text is reviewed."

Avoid:

- "best nonprofit"
- "AI-approved"
- "objective score"
