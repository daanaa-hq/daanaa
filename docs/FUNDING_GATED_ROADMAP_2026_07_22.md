# Funding-Gated Roadmap: Stage-Based Implementation
## Board Meeting July 22, 2026

**Core Principle:** Each stage of work (Decisions 1–15) is tied to a funding requirement. Clear spending gates + clear success milestones = reason to fundraise.

**Why this matters:** Without funding, we don't execute. With funding gates, we have concrete ask for investors/grantmakers.

---

## Four-Stage Model

```

$0–50K raise               $100–200K raise            $200–500K raise          $500K–1M+ (B2B ESG)
───────────────────────────────────────────────────────────────────────────────────────────────
Decisions: 1,2,3,6,7,8     Decisions: 4,5,9,10,11     Decisions: 12,13,14,15   Decisions: full ops
(6 decisions)              (5 decisions)              (4 decisions)            (all 15 operational)

3–5 schools               Full product               Multi-city pilot          National + revenue
500–1K students           10–20 schools              50–100 schools           1M+ students
```

## How to Use This Roadmap

**Before board meeting:**
- Board agrees: which decisions are Stage 1 vs. 2–4?
- Finance estimates: does cost/revenue math align?
- Founder confirms: can you execute this timeline?

**After board meeting (Day 1):**
- Assign Stage 1 implementation owners
- Begin Stage 1 fundraising (personal network, grants, angels)
- Set Gate 1 success metrics (Q4 2026 pilot review)

**After each stage gate:**
- Review metrics (hit targets?)
- Decide: proceed to next stage?
- Begin next stage fundraising (with pilot data as proof point)

## Why This Works

**For Investors/Grantmakers:**
- Clear milestones (Stage 1, 2, 3, 4)
- Measurable success metrics (student adoption, revenue, compliance)
- De-risked: each stage proves viability before big spend
- "We're not burning $1M blindly; we're testing $25K, then $100K, then $250K"

**For Daanaa:**
- No spending without reason (fundraising provides reason)
- Revenue offsets costs (by Stage 3–4, self-sustaining)
- Governance matures with scale (COI policy, insurance, compliance)
- All 15 decisions fit into rational execution order (not all at once)

**For Nonprofits/Students:**
- Consistent product improvement (new features each stage)
- Safety/compliance improves (insurance, formal governance)
- Long-term viability (revenue model removes fundraising dependency)
