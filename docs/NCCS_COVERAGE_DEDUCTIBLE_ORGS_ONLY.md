## Executive Summary

When filtering for **tax-deductible organizations only** (the universe of nonprofits that receive public donations), Daanaa coverage is:

- **Total tax-deductible 501(c)(3)s:** 1,946,935
- **With NCCS financial data:** 476,757
- **Coverage:** 24.5%
- **Data gap:** 1,470,178 organizations (75.5%)

This is slightly lower than the all-status average (27.5%) because suspended/revoked organizations file fewer complete 990s.

## Actionable Gaps (Deductible Orgs Only)

### Gap 1: Microdonor Organizations (<$50K)

**Scale:** 618K deductible orgs (31.8%) have <$50K revenue but only **8.2% have NCCS data**

**Why this matters:**
- These are grassroots organizations, community groups, volunteer-run nonprofits
- Donors want to know: "Does this org have reserves?"
- Currently, Daanaa can't answer that question for 567K organizations

**Possible causes:**
- Form 990-N filers (simplified form, <$50K revenue) don't report balance sheet
- These orgs may not file complete 990s at all
- May lack formal financial records

**Recommendation for NCCS:**
- Audit Form 990-N completeness for balance sheet (Part X)
- Identify if <$50K filers are excluded by design or by filing rate

### Gap 2: Faith Communities (X)

**Scale:** 145K deductible faith organizations but only 15.1% have NCCS data

**Why this matters:**
- Largest single NTEE category by count
- Different financial models (tithing, endowments, restricted funds)
- Donors need category-specific benchmarks

**Possible causes:**
- Form 990 filing rates lower for faith orgs?
- Different accounting practices (restricted funds not reported as net assets)?
- May use 990-N more frequently?

**Recommendation for NCCS:**
- Compare Form 990 vs 990-N filing rates for X (religion) vs S (social services)
- Investigate if faith org accounting practices differ in NCCS extraction

### Gap 3: Liabilities Data (Universal)

**Scale:** For 1.47M deductible orgs, we cannot measure debt burden

**Why this matters:**
- Debt is critical for: housing nonprofits, capital campaigns, distressed organizations
- Can't identify organizations with unsustainable debt loads

**Current status:** Only 356K deductible orgs have liabilities data from NCCS

**Recommendation for NCCS:**
- Verify liabilities field completeness in Form 990 Part X
- Identify which NTEE categories systematically omit liabilities reporting
