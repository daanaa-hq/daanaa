# Daanaa Carousel Design System

**Version 1.0** — Signature format for LinkedIn nonprofit carousels

## Core Principle: Memorable. Readable. Simple. Modular.

Every carousel follows the same visual system, making Daanaa instantly recognizable while allowing content flexibility.

---

## Visual Identity

### Color Palette
- **Primary Navy:** `#0A1628` (authority, trust)
- **Accent Gold:** `#C9A96E` (warmth, human-centered)
- **Text Cream:** `#F5F0EB` (premium, readable)
- **Signature Accent:** Gold circle or square mark (top-right corner)

### Typography
- **Headlines:** Cormorant Garamond Italic (expressive, distinctive)
- **Body:** DM Sans Regular (clean, scannable)
- **Emphasis:** DM Sans SemiBold (hierarchy, labels)

### Spacing
- 56px margins (left/right)
- 48px module spacing (between sections)
- Premium white space (not crowded)

---

## Slide Types

### 1. Cover Slide (1/6)
**Purpose:** Hook attention, establish topic

**Layout:**
- Signature accent circle (top right)
- "DAANAA" label + gold rule
- Large, italic headline (stops scroll)
- Supporting subtitle
- "Swipe to explore →" cue
- Logo stamp + footer URL

**Content:**
- Headline: Question or bold claim (8-12 words)
- Subtitle: Brief context (1 sentence)

**Example:**
```
DAANAA
━━━━━━

Nearly Half Can't Survive
a Funding Gap

The reserve crisis affecting 1.7M nonprofits

[Swipe to explore →]
```

---

### 2-4. Content Slides (2-5 of 6)
**Purpose:** Tell the story in 3 acts (Data → Meaning → Stakes)

**Layout:**
- Signature accent circle (top right)
- "PART X: THE ___" label + gold rule
- Headline (clear, specific)
- **Stat Box:** Visual container with:
  - Huge number (108pt, gold)
  - Short descriptor (cream, readable)
- Body text (statistic + context + consequence)
- Source attribution

**Content Structure:**
```
Part 1: The Data
━━━━━━

Small Orgs Have Zero Cushion

┌─ 40% ─┐
Nonprofits with Less Than 3 Months of Funds

Organizations under $500K in annual funding
invest every dollar into programs—admirable,
but dangerous. One disruption shuts down services.

— IRS 990 Filings, 1.7M active U.S. nonprofits
```

---

### 5. Insight Slide (5 of 6)
**Purpose:** One memorable takeaway, worth saving/sharing

**Layout:**
- "KEY INSIGHT" label + rule
- Headline (what this means for the sector)
- Centered, bold statement (2 words to 1 sentence)
- Source

**Content:**
```
Key Insight
━━━━━━

Reserve Stability = Impact Multiplier

Funders who support reserve-building don't just
save organizations. They multiply impact.

— Daanaa nonprofit analysis
```

---

### 6. CTA Slide (6 of 6)
**Purpose:** Drive action + commitment

**Layout:**
- Signature accent square (top right)
- Headline (action-oriented)
- Subtitle (2 benefit lines, cream text)
- Gold button with dark text
- Follow/subscribe cue

**Content:**
```
See Which Nonprofits Need Reserves Most

Explore financial health data for 1.7M nonprofits
Make informed funding decisions

┌────────────────────┐
│   daanaa.org       │
└────────────────────┘

Follow Daanaa for nonprofit insights
```

## Modular Elements

### Signature Accent
- **Circle** (content slides): Softness, inclusion
- **Square** (CTA slides): Clarity, action

**Location:** Top-right corner, 28-30px size

### Stat Box
- Navy background with gold border
- Large number (108pt Italic Gold)
- Short descriptor (30pt Cream)
- Breathing room

### Rule Decoration
- Gold horizontal line (80-160px wide)
- Separates sections, signals importance

### Logo & Footer
- Logo stamp: bottom-left
- Footer URL: bottom-center (clickable in PDF form)
- Slide counter: bottom-right (light text)

---

## Responsive Principles

### Mobile (on download/viewing)
- All type remains readable (no scaling down)
- Stat boxes scale proportionally
- Margins maintained
- White space preserved

### Readability Standards
- Body text: ≥16px, 4.5:1 contrast minimum
- Headlines: 60-108pt, high contrast
- Line height: 1.4-1.5 (breathing room)

---

## Implementation Notes

### Consistency Rules
1. **Every carousel** has the signature accent (circle or square)
2. **Every stat** gets a visual container (stat box)
3. **Every headline** is 1-2 lines, no more
4. **Every CTA** button is 120px tall, gold-filled
5. **Colors** never vary — use the palette exactly

### Do's
✓ Use premium white space  
✓ Let text breathe  
✓ Make stats visual (boxes, not floating text)  
✓ One stat per content slide  
✓ Signature accents on every slide  
✓ High contrast (cream on navy, gold accents)  

### Don'ts
✗ Add decorative shapes (blobs, gradients, patterns)  
✗ Clutter with multiple stats per slide  
✗ Use system fonts (use Cormorant + DM Sans)  
✗ Break the color palette  
✗ Reduce margins or white space  
✗ Center-align text unnecessarily

## Output Specifications

**Canvas:** 1080 × 1350px (4:5 portrait, LinkedIn optimal)  
**Format:** PDF (multi-page, slide sequence)  
**File Naming:** `daanaa_{carousel_type}_{YYYYMMDD_HHMMSS}.pdf`  
**Quality:** 150 DPI minimum for printing, 72 DPI for screen

---

## Evolution Path

This system is locked for consistency. Improvements come as:
1. **Font pairs** (test new typeface combinations)
2. **Color accents** (add secondary colors for carousel types)
3. **Stat visualizations** (add charts, bars, % indicators)
4. **Slide variants** (new types keeping core principles)

Never: change core colors, remove white space, add decorative noise.
